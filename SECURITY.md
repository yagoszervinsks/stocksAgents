# Política de segurança

Não inclua credenciais, tokens, dados pessoais ou informações financeiras sensíveis em
issues, pull requests ou commits.

Para relatar uma vulnerabilidade, contate o mantenedor de forma privada pelo GitHub e
inclua passos mínimos de reprodução, impacto e versões afetadas. Não publique uma prova
de conceito que exponha usuários, dados ou serviços de terceiros.

Este projeto não aceita mudanças que introduzam segredos no repositório. Use variáveis de
ambiente documentadas em `.env.example` quando houver configuração necessária.
